## Status of each step — what's actually verified vs not

| Step | What it does | Tested in sandbox? | Needs before real use |
|------|---------------|---------------------|------------------------|
| 1 | Synthetic point cloud generator | YES — fully tested | Nothing, ready as-is |
| 2 | Point cloud encoder | YES — but this is a **PLACEHOLDER**, not real PointNeXt | Replace with real PointNeXt (GPU + compiled CUDA ops, Kaggle) |
| 3 | Projection layer (512→4096) | YES — fully tested | Verify 4096 matches your actual LLaMA's `hidden_size` |
| 4 | Load LLaMA-3-8B (4-bit) | NO — no GPU/gated weights in sandbox | Meta license approval, HF token, GPU (Kaggle) |
| 5 | Full forward pass wiring | PARTIAL — encoder+projector part tested, LLaMA part not | Depends on Step 4 working |
| 6 | Training loop | NO — depends on Step 5 | Depends on Steps 4+5 working |
| 6b | Dataset class | YES — fully tested on dummy QA json | Replace dummy_qa_pairs.json with real annotations |
| 7 | Evaluation metrics (EM@1, BLEU-4) | YES — fully tested | Cross-check normalize_answer() against ScanQA's actual eval script |
| 8 | Data quality validator | YES — fully tested, catches injected bad data | Run on every real RealSense capture |

## Run order locally (no GPU needed, all of this works on your laptop)
```bash
cd idea4-frozen-alignment-3dqa
python scripts/step1_dummy_data.py
python scripts/step2_pointcloud_encoder.py
python scripts/step3_projection_layer.py
python scripts/step5_full_forward_pass.py   # partial test only
python scripts/step6b_dataset.py
python scripts/step7_evaluation_metrics.py
python scripts/step8_data_validator.py
```

## What only runs on Kaggle (GPU required)
- step4_load_llama.py (needs GPU + HF gated model access)
- step5_full_forward_pass.py (full version, with real LLaMA)
- step6_training_loop.py (real training)
- step2 — once you swap in real PointNeXt instead of the placeholder

## The single most important honesty flag in this whole pipeline
Step 2's encoder is NOT real PointNeXt. It's a simple MLP that produces
correctly-shaped output so the rest of the pipeline can be built and tested.
No real research result can come from this placeholder. Setting up real
PointNeXt with its custom CUDA kernels on a GPU machine is the highest-risk
unsolved task in this entire project — don't mistake pipeline progress here
for progress on that risk.
